AgroVerde - Irrigação Inteligente Movida a Sol
AgroVerde é um projeto conceitual de site/aplicativo que apresenta uma solução sustentável para o agronegócio: um sistema de irrigação inteligente alimentado por energia solar e sensores de umidade do solo.

Visão Geral
O projeto consiste em um site estático (HTML, CSS e JavaScript puro) que demonstra a ideia de tecnologia sustentável aplicada ao campo brasileiro.

Funcionalidades Principais
Apresentação da solução — explica como painéis solares, sensores de umidade e monitoramento IoT trabalham juntos
Calculadora de economia — simulação interativa que mostra quanta água e dinheiro uma fazenda pode economizar com o sistema
Design responsivo — adapta-se a celulares, tablets e desktops
Animações suaves — efeitos de entrada ao rolar a página
Imagens temáticas — fotografias de agricultura sustentável
